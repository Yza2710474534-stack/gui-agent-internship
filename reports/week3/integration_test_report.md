## 日志内容

长任务运行器按 JSONL 记录以下事件：任务开始、步骤开始、步骤结果、计划重试、任务完成或任务失败。每条记录包含时间、步骤编号、尝试次数、执行结果、失败原因和耗时。截图路径、OCR 结果或页面变化信息可以放入 `evidence` 字段。

## 当前边界

获得 屏幕录制权限的终端中运行项目截图代码，得到 1470×956、坐标比例 1:1 的真实 Chrome 截图。项目 EasyOCR 识别出搜索框中的 `gui agent`，以及 `gui-agents`、`GitHub`、`Topics` 和中文 GUI Agent 文章等结果证据；自动完成判断再次通过。
